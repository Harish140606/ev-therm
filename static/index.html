EV Battery Thermal Control Simulator · PID vs MPC

Software simulation · no hardware

Keeping a battery cool without wasting energy

Current flowing through a battery's internal resistance produces heat. The cooler must hold the battery near a target temperature, but running it hard costs electrical energy. This simulator runs two controllers on the same simulated battery, with the same load and starting temperature.

PID

Reacts to the present error e = T − Ttarget: proportional to how hot it is, integral of past error, derivative of how fast it is changing.

MPC

At every step it predicts the temperature over a short horizon with the battery model, solves an optimisation (SciPy SLSQP) for the best cooling plan, applies the first move, and repeats.

Performance metrics

    Mathematical model & explanation

    Thermal model (single node)

    C · dT/dt = Qgen − Qcool
    Qgen = I² Rint    Qcool = Kcool · u · (T − Ta),   0 ≤ u ≤ 1
    Tk+1 = Tk + (Δt / C) · (Qgen,k − Qcool,k)

    Forward Euler, stable when Δt·Kcool/C < 1 (checked before each run). Hottest steady state at full cooling: T = Ta + Qgen/Kcool. If that is above the target, no controller can reach it.

    PID

    u = clip(Kpe + KiΣe·Δt + Kd(ek − ek−1)/Δt, 0, 1)

    e = T − Ttarget; positive error means too hot, so more cooling. Anti-windup freezes the integral while the output is saturated. Derivative is zero on the first sample.

    MPC

    min Σk=0..N−1 qT(T̂k+1 − Ttarget)² + ruuk² + rdu(uk − uk−1)²
    s.t. 0 ≤ uk ≤ 1,   |uk − uk−1| ≤ Δumax

    T̂ is predicted with the same model; future current is forecast as the present current held constant. Only u0 is applied; the shifted plan warm-starts the next solve. If SLSQP fails, the previous command is held and the failure is reported.

    Energy & metrics

    Pcool = Pmax u³    E = ΣPcoolΔt [J]    EWh = E / 3600

    The cubic law is an assumption (fan/pump affinity law). Heat removed (thermal) and electrical energy are different quantities. Metrics: peak T, MAE, RMSE, cooling energy, max u, time above limit, time at full cooling while above target.

    Assumptions & limitations

    One lumped temperature (no cell-to-cell gradients); constant Rint; simplified cooling to ambient; illustrative parameters, not a specific commercial pack; no sensor noise; MPC's model equals the plant; PID has no slew limit while MPC has Δumax.
